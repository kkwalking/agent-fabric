08 / OBSERVABILITY & CONTROL

过程不是黑箱

每一次运行，
都留下可核对的痕迹。

统一事件格式、实时 SSE、成本与产物都挂在 Run 上；权限与边界在执行前就确定。

EVENTS & LOGS

标准事件 + 实时流，REST 可查询，SSE 可订阅。

USAGE & COST

Token、请求数、时长与估算成本，按 Model / Provider / 日期聚合。

ARTIFACTS

Diff、报告、测试结果、构建输出与最终结果随 Run 保存。

EXECUTION POLICY

最大时长、模型调用、Token、Cost、CPU / Memory、网络与 Shell 权限。

SECRETS

统一管理、按需注入；值不出现在日志或事件里。

ACTIVITY

近 26 周活动热力图，按费用或 Token 切换指标。
