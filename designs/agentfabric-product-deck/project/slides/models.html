06 / MODELS & PROVIDERS

模型不是某个工具的私事

Provider 与 Model，
是平台的公共配置。

接口格式、Base URL、额外 Header、API Key、参数与别名，都在同一处维护；运行时只负责调用。

01

Provider

增删改查、启用/禁用、连通性测试

02

Model

所属 Provider、参数、Alias、成本口径

03

Secrets

Key 不进入日志、事件或容器镜像

04

Run

每次执行自由选择运行时与模型

5

种 Provider 接口格式：OpenAI Responses、Completions、Anthropic、兼容、自定义。

PROVIDER → MODEL

Model 不绑定 Provider 实现。换个入口，模型名与参数仍然成立。

统一模型目录，运行时自由选择。
