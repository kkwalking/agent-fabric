04 / THE MODEL

三个对象，一条生命周期

Workspace → Task → Run。

工作区定义位置，任务定义意图，运行执行一次 Agent。Runtime 只负责“在哪里跑”。

01 / DURABLE

Workspace

本机上的一个目录，也可以只是一个空目录。任务在原地执行，不 clone，不 checkout，不建分支。

默认 Runtime / Model / 看板设置

02 / ONE INTENT

Task

一次任务只指定：工作区、运行时、模型，以及可选的 Env、Secrets、资源限制与超时。

没有 Project 层，没有分支决策

03 / DISPOSABLE

Run

每个 Run 记录 phase 与 status，失败可按阶段重试；日志、事件与产出挂在这次执行上。

Pending → Running → Completed / Failed

一条原则：容器可丢弃，工作区是持久的。

Harness 的原生 Session 只保存不透明引用，不统一、不转换。
