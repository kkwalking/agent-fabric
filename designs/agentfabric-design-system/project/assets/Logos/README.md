# Logos

The single source mark is `AgentFabric-logo.svg`, the same geometry used by the in-app `BrandMark` and the Dock icon. It is a 1024px square with a deep navy tile radius of 205px and three woven strands: cyan, warm orange and violet.

- Use the full tile on dark or brand surfaces; use the glyph alone only where the row already carries a surface, as in the app sidebar.
- Clear space: one tile corner radius on all sides.
- Do not recolour, outline, crop or add a glow. The only permitted background is white, `surface`, or the logo tile's own navy.
