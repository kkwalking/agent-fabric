# Card

The default surface for a task, board card or settings group: white, hairline border, 12px radius and one low shadow.

- Keep one idea per card. The eyebrow names the category; the title states the object; the body adds only what the title cannot.
- Use the footer for one status or one action, not a toolbar.
- Cards never nest. If a card needs another card, it is a table or a page section.
- The card is not a button: interactive cards must carry a focus ring and a clear hover state.
