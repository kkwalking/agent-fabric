# Button

The product has one button shape. **Quiet** is the default; **Primary** is the dark ink fill; **Accent** is the burnt-orange fill reserved for a single, page-level action.

- Use a 32px height for standard actions and the `small` modifier only inside dense rows.
- Label with a verb phrase: “新建工作区”, “Run task”, “Open kanban”. Never use “OK”.
- Primary may appear at most once per view. If two primary actions compete, one is actually quiet.
- Disabled buttons keep their geometry; only opacity changes.
