# Badge

A compact status pill with a 6px dot. It labels state, not category: one or two words, never a sentence.

- Neutral: an unclassified or idle state.
- Info: running, starting or live information.
- Success: completed.
- Warning: pending or waiting.
- Danger: failed, timed out or blocked.
- Review: waiting for a human review or a review-specific state.

Use sentence case in Chinese copy; the dot is the only ornament.
